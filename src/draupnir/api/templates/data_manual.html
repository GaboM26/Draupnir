Data manual

Where the numbers come from

Every figure comes from the SEC's quarterly Financial Statement Data Sets: the XBRL facts companies file with their 10-K and 10-Q reports. Each loaded quarter adds the filings submitted during that quarter.

Columns

Line item
A readable name for the XBRL tag. Common tags get a curated name; the rest are the tag split into words.
Filer's label
The label the company itself used on its statement.
Value
The reported amount, in the unit shown (USD, shares, or USD per share).
Period
Fiscal year and quarter the filing reports. FY marks an annual report.
Quarters
How many quarters the value spans. 0 means a single quarter or a balance at a point in time; 4 means a full fiscal year. Companies report cash flows year-to-date and the fourth quarter only as the full year, so Draupnir derives single-quarter values by subtracting the previous cumulative figure.

Tickers and periods

A ticker is guessed from the name of the filing's XBRL file, so it is usually, not always, the exchange ticker. Fiscal periods follow each company's own fiscal year, which need not match the calendar year.

Downloads

Each statement page can be downloaded as CSV, or fetched as JSON from /REST/<ticker>_<period>.
